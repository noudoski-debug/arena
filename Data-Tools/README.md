# Data-Tools 1.0

Python CLI для исследования **публичных источников** с результатом в автономном интерактивном HTML-графе. Можно указать произвольный публичный username — подтверждать владение аккаунтом не нужно.

**Возможности:** Telegram username/доступные публичные публикации, поиск интернета по словам, социальная поисковая выдача, публичный GitHub и разрешённые локальные CSV/JSON/JSONL. Закрытые переписки, номера телефонов, пароли, сессии и «все слитые базы» не предоставляются.

## Установка

Нужны Python **3.10+**, интернет для установки зависимостей и реальных запросов, современный браузер для отчётов.

Linux/macOS (из каталога распакованного проекта):

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python Data-Tools.py --help
```

Windows PowerShell:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Если политика PowerShell запрещает активацию, вызывайте `.\.venv\Scripts\python.exe` напрямую.

### Android / Termux

Работайте из домашнего каталога Termux, а не из `/sdcard`: там не поддерживаются необходимые venv права/ссылки.

```bash
pkg update
pkg install python clang make pkg-config libffi libsodium
python -m venv .venv
. .venv/bin/activate
SODIUM_INSTALL=system python -m pip install -r requirements.txt
python Data-Tools.py demo -o demo.html
```

Для просмотра можно использовать `termux-open demo.html`. Доступность команды и открытие локального HTML зависят от Android/браузера; при необходимости передайте файл браузеру через файловый менеджер. Установка и выполнение на реальном Android в этой сборке не проверялись.

## Быстрый просмотр без ключа

```bash
python Data-Tools.py demo -o demo.html
```

Готовый пример: **`examples/demo.html`**. В нём 12 узлов и 11 связей, исключительно вымышленные данные. Демо не обращается ни к KeyAuth, ни к поисковым источникам.

HTML содержит все CSS, JavaScript и данные. Работают перетаскивание карты/узлов, масштаб, поиск по узлам, фильтры типов, карточки фактов, ссылки на источники и выгрузка JSON. Никаких CDN или фоновых сетевых запросов; переход по ссылке на источник выполняется только пользователем. Не редактируйте встроенные данные вручную: импорт произвольного графа в интерфейсе не поддерживается.

## Лицензия KeyAuth

В `data_tools/licensing.py` уже заданы предоставленные параметры:

```text
name          = Data-Tools
ownerid       = 2bTkDP2v6c
version       = 1.0
hash_to_check = getchecksum()
```

Это **идентификаторы приложения, а не лицензионный ключ**. Ключ создаёт владелец приложения в панели KeyAuth. Не присылайте его в чат и не добавляйте в исходники.

1. Получите checksum: `python Data-Tools.py checksum`.
2. Если в приложении включена проверка hash, настройте соответствующий hash и версию `1.0` в панели KeyAuth. Используется MD5 файла `Data-Tools.py` для совместимости с протоколом SDK.
3. Запустите `python Data-Tools.py auth-check`: программа запросит ключ скрыто в терминале.
4. После успешной проверки запускайте нужную команду; каждый отдельный запуск поиска снова проверяет лицензию.

Для автоматизации поддерживается переменная окружения `DATA_TOOLS_LICENSE`. Устанавливайте её через менеджер секретов/средства своей оболочки, не вписывая ключ в историю команд. Ключа в аргументах CLI нет. Автозагрузка `.env` не реализована. В HTML/JSON не экспортируются ключ, HWID, API-токены и сессия KeyAuth.

**Поведение клиента:** HTTPS POST `https://keyauth.win/api/1.3/`, сначала `init`, затем `license`; проверяются подпись Ed25519 и отклонение времени не более 25 секунд в обе стороны. Перенаправления и неподписанные ответы отклоняются. Установите правильные часы устройства. При ошибке лицензии источники не опрашиваются и отчёт не создаётся. `demo`, `checksum`, справка доступны без ключа; все реальные команды, в том числе `local`, требуют ключ.

Вместо серийного номера устройства в поле `hwid` передаётся случайный стабильный ID установки. Хранение: `$XDG_CONFIG_HOME/data-tools/device-id` или `~/.config/data-tools/device-id`. Это **не аппаратный, не неклонируемый HWID**; не публикуйте/не переносите этот файл. Уже привязанным к другому HWID ключам может потребоваться сброс или изменение настроек владельцем приложения. Удаление ID не снимает серверную привязку лицензии.

Python-клиент можно модифицировать, а MD5 launcher не защищает остальные модули от подмены. Это не система сильной анти-тампер защиты. Автоматического обновления/запуска скачанного кода нет. `auth-check` — проверка запуска, а не непрерывный контроль отзыва лицензии.

**Реальный вход в это приложение пока не проверен:** лицензионный ключ не предоставлялся. Тесты проверяют криптографию и отказ при ошибках на локальных фикстурах, а не действительность приложения в панели.

## Команды

Примеры используют публичный пример username; наличие конкретного аккаунта/результатов не гарантируется. При запуске в терминале ключ вводится скрыто.

```bash
# Публичная страница Telegram и доступный preview публикаций
python Data-Tools.py telegram research_demo -o telegram.html
python Data-Tools.py telegram @research_demo --words "Python" --limit 10 -o posts.html

# Поиск интернета по словам
python Data-Tools.py search "open source graph tools" --limit 20 -o web.html

# GitHub + Telegram + социальная выдача + явно непроверенные шаблоны ссылок
python Data-Tools.py social research_demo -o social.html

# Публичный профиль GitHub и публичные репозитории
python Data-Tools.py github octocat --limit 10 -o github.html

# Разрешённый локальный набор: ищутся только поля белого списка
python Data-Tools.py local "Aurora" examples/public_records.csv --authorized -o local.html

# Дополнительный JSON, явное разрешение перезаписи
python Data-Tools.py search "public research" -o web.html --json web-graph.json --force
```

Не передавайте URL вместо username. Telegram принимает `username` или `@username`, но не invite-ссылки. Поиск нечувствителен к регистру; `--words` фильтрует доступные публикации конкретного username, а не весь Telegram.

По умолчанию создаётся `data-tools-report.html`; существующие файлы без `--force` не заменяются. Выходные HTML/JSON должны различаться и не могут совпадать с входными файлами. При `--force` отдельный файл заменяется атомарно; пара HTML+JSON не является единой транзакцией. Новые отчёты получают права `0600`, где файловая система поддерживает POSIX-права.

## Источники и достоверность

| Источник | Что делает | Ограничения |
|---|---|---|
| Telegram | Загружает публичную `t.me/username` и `/s/username`, разбирает текст доступных публикаций | Без входа в аккаунт, MTProto, закрытых чатов, телефонов и полного архива. Общая страница не подтверждает существование аккаунта. Разметка может измениться |
| Веб | Bing RSS по умолчанию; Brave Search API при наличии ключа | RSS не гарантированный API, возможны блокировки/капча/неполная выдача. Содержимое найденных сайтов не скачивается. Brave выдаёт до 20 результатов за запрос |
| GitHub | Публичные метаданные профиля и до `--limit` публичных репозиториев | Без email/location/приватных репозиториев; возможны API-лимиты |
| Соцсети | Социальная выдача поисковика, Telegram/GitHub; ссылки-кандидаты VK/Instagram/TikTok/X/YouTube | **Шаблон ссылки — не найденный аккаунт.** Наличие и принадлежность не проверены. Совпадение ника не означает общую личность |
| Локальные файлы | Поиск по разрешённым UTF-8 CSV, JSON-массиву объектов, JSONL | До 10 файлов по 20 МБ, до 100 000 просмотренных записей/файл; не база утечек |

`--limit`: 1–50, по умолчанию 20. Лимит применяется к источнику/файлу, а не ко всему графу; объединённый `social` может дать больше узлов. Telegram preview и поисковик могут вернуть меньше. Профиль, поисковый источник и корневой запрос также являются узлами, поэтому число узлов не равно числу результатов.

Необязательные переменные окружения:

- `DATA_TOOLS_BRAVE_KEY` — ключ Brave Search API вместо RSS;
- `DATA_TOOLS_GITHUB_TOKEN` — токен GitHub с минимальными необходимыми правами для увеличения API-лимита. Не давайте приложению лишние права.

Для локального импорта доступны поля: `title`, `name`, `username`, `organization`, `description`, `summary`, `text`, `url`, `website`, `tags`, `source`, `date`, `category`, `project`, `id`. Остальные поля **не ищутся и не импортируются**. Записи с этими полями должны быть публичными либо законно доступными для вашего использования; `--authorized` подтверждает право использования, а не владение аккаунтом. Полный путь локального файла в отчёт не добавляется, но basename сохраняется.

Email, похожие на телефоны числа и текстовые `password/token/secret=…` маскируются эвристически. Это **не гарантия полной анонимизации**: возможны пропуски и ложные совпадения. Из ссылок удаляются query/fragment, поэтому часть ссылок может стать менее точной. Перед передачей HTML/JSON другим людям проверьте содержимое; отчёты могут раскрывать публичные username и связи. Не используйте инструмент для преследования, деанонимизации или поиска чужих секретов.

Статусы источников: `ok`, `empty`, `partial`, `unknown`, `error`. Сбой источника не означает, что аккаунт отсутствует. HTML при ошибке источников может содержать только диагностику. При частичном результате доступные факты сохраняются.

Коды завершения: `0` — команда выполнена (возможны пустые/частичные результаты; смотрите статусы), `2` — ошибка аргументов/файла либо все источники завершились ошибкой, `3` — ошибка лицензии, `130` — отмена/EOF скрытого ввода. Встроенные ошибки `argparse` также возвращают `2`.

## Тесты и проверка сборки

```bash
python -m unittest discover -s tests -v
```

Для отдельной проверки DOM-интерфейса нужен Node.js 18+ (не зависимость приложения):

```bash
npm install --prefix build/ui-test --no-audit --no-fund jsdom@26
NODE_PATH="$PWD/build/ui-test/node_modules" node tests/test_ui.cjs
```

24 Python-теста покрывают локальные фикстуры адаптеров, фильтрацию/маскирование, XSS-safe JSON, запись файлов, криптографию/время KeyAuth, запрет неподписанных ответов и запрет сбора при ошибке лицензии. DOM-тест проверяет 12 узлов, фильтры, карточку, ссылки, масштаб и подписи. Это не визуальный тест реального браузера. Реальные сетевые запросы к Telegram, поисковикам и лицензированному приложению в этой среде не проверялись.

Для повторной сборки исходного ZIP: `python tools/package.py`. В архиве есть `SHA256SUMS.txt` для всех включённых файлов; рядом создаётся SHA-256 самого ZIP.

Зависимости и происхождение протокола: `THIRD_PARTY.md`. Архив не содержит venv, лицензионных ключей, device-id, стороннего SDK и реальных результатов поиска.
